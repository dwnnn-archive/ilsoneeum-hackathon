# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Mobile-first HTML, CSS, and JavaScript frontend with a Node.js API; deployable to Azure App Service. Core demo interactions use browser storage and do not require AI credentials.

## Users

Cheongdo County farmers, including older adults who need help with seasonal farm work, and young people looking for short-term rural work and agricultural experience.

## Product Purpose

Connect local farms with young workers through a mobile-friendly web service. Farmers can share seasonal work needs, while young people can discover and apply for suitable jobs.

## Positioning

A local work-matching service that puts each farm task's work description, schedule, and pay in front of prospective workers so both sides can make an informed match.

## Operating Context

Farmers create work listings when they need seasonal help. Young people browse opportunities, review the conditions, and submit an application.

## Capabilities and Constraints

The prototype demonstrates sample-job discovery, applications, and farmer posting flows. Demo data remains in browser storage; applications are not delivered to farms. Optional server-side assistance uses GitHub Copilot SDK to compare supplied listings and Microsoft Agent Framework to suggest posting descriptions. Azure deployment is supported by a container configuration, but no live Azure service or provider connectivity is claimed.

## Brand Commitments

The service name is 일손이음. The user-provided `cheongdo-ilson-source (3)` files set the visual reference: warm orange accents, rounded white surfaces, and a simple Cheongdo fields illustration.

## Evidence on Hand

The product brief establishes the Cheongdo County context and the job details to communicate: work description, schedule, and pay. No real listings, testimonials, photographs, or verified program outcomes have been provided; demo content must be treated as illustrative.

## Product Principles

- Make work conditions easy to understand before applying.
- Reduce friction for farmers sharing seasonal work needs.
- Make short-term rural work more discoverable to young people.
- Clearly distinguish illustrative demo content from verified opportunities.
- Keep AI optional, reviewable, and separate from authoritative work conditions.
